# 众安车险C端设计规范 (ZA Auto Insurance Design System)

## Description
众安车险C端移动端设计规范，用于 Figma 设计稿转代码时确保生成的页面符合公司设计标准。涵盖颜色体系、字号体系、圆角、布局、导航栏、按钮、图标、反馈组件和交互规则。

## Trigger
当用户使用 Figma 设计稿生成车险相关页面或组件代码时，自动参考此规范。

## 6. 视觉风格层 (Visual Style - Glassmorphism)

整体视觉采用**苹果 iOS 毛玻璃(Glassmorphism)**风格，营造科技感和互联网感。

### 6.1 毛玻璃效果

#### 卡片毛玻璃
```css
/* 一级卡片 — 主要容器 */
background: rgba(255, 255, 255, 0.72);
backdrop-filter: blur(20px) saturate(180%);
-webkit-backdrop-filter: blur(20px) saturate(180%);
border: 1px solid rgba(255, 255, 255, 0.5);
box-shadow: 0 2px 16px rgba(0, 0, 0, 0.04), 0 0 1px rgba(0, 0, 0, 0.06);
```

#### 导航栏/底部栏毛玻璃
```css
/* 固定栏 — 更强的模糊 */
background: rgba(255, 255, 255, 0.78);
backdrop-filter: blur(24px) saturate(200%);
-webkit-backdrop-filter: blur(24px) saturate(200%);
border-bottom: 0.5px solid rgba(0, 0, 0, 0.06);
```

#### 弹窗/面板毛玻璃
```css
/* 弹窗 — 突出层级 */
background: rgba(255, 255, 255, 0.85);
backdrop-filter: blur(40px) saturate(200%);
-webkit-backdrop-filter: blur(40px) saturate(200%);
box-shadow: 0 8px 40px rgba(0, 0, 0, 0.12), 0 0 1px rgba(0, 0, 0, 0.08);
```

### 6.2 页面背景
- **不再使用纯色背景**，改用带品牌色的**渐变光斑**背景
- 基底色保持 `#F6F6F6`，叠加 2-3 个柔和渐变光斑
- 投保前链路光斑：橙色系 `rgba(255, 94, 19, 0.06)` ~ `rgba(255, 94, 19, 0.12)`
- 投保后链路光斑：绿色系 `rgba(14, 211, 152, 0.06)` ~ `rgba(14, 211, 152, 0.12)`
- 光斑通过 `radial-gradient` 实现，位置在页面顶部和右侧，营造光照氛围

### 6.3 阴影体系
| Token | 值 | 用途 |
|-------|-----|------|
| `shadow-card` | `0 2px 16px rgba(0,0,0,0.04), 0 0 1px rgba(0,0,0,0.06)` | 卡片柔和阴影 |
| `shadow-float` | `0 8px 40px rgba(0,0,0,0.12), 0 0 1px rgba(0,0,0,0.08)` | 浮层/弹窗阴影 |
| `shadow-button` | `0 4px 16px rgba(255,94,19,0.25)` | 主要按钮发光阴影（橙色） |
| `shadow-button-green` | `0 4px 16px rgba(14,211,152,0.25)` | 主要按钮发光阴影（绿色） |

### 6.4 边框与分割
- **卡片边框：** `1px solid rgba(255,255,255,0.5)` — 半透明白色边框，增强玻璃层次
- **分割线：** `0.5px solid rgba(0,0,0,0.06)` — 极细分割线替代实色分割线
- **选中态边框：** `1.5px solid` 品牌色 + 同色极浅底色（如 `rgba(255,94,19,0.06)`）

### 6.5 圆角体系（升级）
为了配合毛玻璃风格，圆角整体加大：
| Token | 值 | 用途 |
|-------|-----|------|
| `radius-large` | 20px | 大卡片、弹窗、底部面板 |
| `radius-regular` | 12px | 常规卡片 |
| `radius-small` | 8px | 小元素、险种项、输入框 |
| `radius-xsmall` | 4px | 极小元素、标签 |

### 6.6 动效增强
- **卡片入场：** `fadeInUp` 动画，从下方 12px 淡入，duration 0.4s，依次延迟 0.05s
- **按钮按压：** `transform: scale(0.97)` + `transition: 0.15s`，触感反馈
- **浮层出现：** 弹窗 `scale(0.92) → scale(1)` + 渐显；底部面板 `translateY(100%) → translateY(0)` 弹簧曲线
- **选中态切换：** `transition: all 0.25s cubic-bezier(0.4, 0, 0.2, 1)`

### 6.7 按钮光感增强
主要按钮添加微妙的光泽效果：
```css
/* 按钮上方叠加一层微光 */
background-image: linear-gradient(180deg, rgba(255,255,255,0.2) 0%, rgba(255,255,255,0) 60%);
```

## 7. 代码生成指引

生成代码时请遵循以下规则：

1. **颜色使用：** 严格使用上述色值，不要随意替换为近似色
2. **字号选择：** 根据内容层级选择对应字号，字体族使用 `PingFang SC` 回退链
3. **间距统一：** 卡片间距 12px，内边距根据层级选择 12px 或 16px
4. **圆角一致：** 大卡片/弹窗 20px，常规卡片 12px，小元素 8px
5. **按钮规范：** 根据按钮位置和重要程度选择对应尺寸和样式
6. **链路区分：** 投保前使用橙色主题(`#FF5E13`)，投保后使用绿色主题(`#0ED398`)
7. **移动端适配：** 基于 375px 宽度设计，使用 rem/vw 等相对单位适配不同屏幕
8. **安全区域：** 底部固定操作栏需考虑 34px 安全区（Home Indicator）
9. **毛玻璃必须应用：** 所有卡片、导航栏、底部栏、弹窗必须使用 `backdrop-filter: blur()` 毛玻璃效果
10. **页面背景：** 使用渐变光斑背景，不使用纯色 `#F6F6F6`
11. **阴影风格：** 使用柔和扩散阴影，不使用硬阴影
12. **入场动画：** 卡片使用 fadeInUp 依次入场，增强页面层次感
