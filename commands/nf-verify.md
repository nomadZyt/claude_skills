# /nf-verify - 验证 NF 实现

## 目的
审查代码、创建验证计划并执行测试。

## 步骤

### 1. 检查 Git 状态
```bash
git status
git diff --stat
```
向用户显示修改了哪些文件。

### 2. 创建提交
```bash
git add .
git commit -m "NF-XXX: [简短描述]"
```

### 3. 审查修改的文件
对每个修改的文件检查：
- [ ] 边界情况处理
- [ ] TypeScript 类型正确
- [ ] 错误处理存在
- [ ] 没有遗留 console.log
- [ ] 没有需要处理的 TODO 注释
- [ ] 代码符合项目约定（CLAUDE.md）

### 4. 创建验证计划
根据 NF 的验证部分：
```markdown
## NF-XXX 验证计划

### 自动化测试
1. 运行单元测试：`npm test`
2. 运行 E2E: `npm run e2e`
3. 检查覆盖率：`npm run coverage`

### 手动测试
1. [步骤 1]
2. [步骤 2]

### 性能
- [ ] Lighthouse 分数 > 90
- [ ] 加载时间 < 2s
```

### 5. 执行验证
运行测试并报告结果：
```
✅ 单元测试：45/45 通过
✅ E2E 测试：12/12 通过
⚠️  手动：需要用户在 Safari 上验证
```

### 6. 建议下一步
```
验证完成。准备关闭 NF-XXX？
运行：/nf-close NF-XXX
```

## 边界情况

- 测试失败 → 诊断并建议修复
- 检测到无关更改 → 要求用户分离提交
