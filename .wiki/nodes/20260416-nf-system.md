# NF System — New Feature 系统

## 概述

用 Markdown 规范驱动并行 Agent 开发的技能包。支持 NF 生命周期管理、多 Agent 协作、项目上下文加载，适合中大型项目开发。

## 公开接口

| 名称 | 类型 | 签名 | 说明 |
|------|------|------|------|
| /nf-new | command | `/nf-new` | 创建新 NF |
| /nf-status | command | `/nf-status` | 查看所有 NF 状态 |
| /nf-explore | command | `/nf-explore` | 加载项目上下文 |
| /nf-verify | command | `/nf-verify` | 验证代码 |
| /nf-close | command | `/nf-close` | 关闭并归档 NF |
| /nf-deep | command | `/nf-deep` | 并行深度分析 |
