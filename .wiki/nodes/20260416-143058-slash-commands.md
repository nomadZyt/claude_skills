# Slash Commands - 斜杠命令集合

## 概述

项目定义的斜杠命令入口，提供便捷的技能触发方式。

## 公开接口

| 接口 | 关联技能 | 说明 |
|------|---------|------|
| `/nf-new` | NF System | 创建新 NF |
| `/nf-status` | NF System | 查看 NF 状态 |
| `/nf-explore` | NF System | 加载项目上下文 |
| `/nf-verify` | NF System | 验证代码 |
| `/nf-close` | NF System | 关闭并归档 NF |
| `/nf-deep` | NF System | 并行深度分析 |
| `/weekly-report` | Weekly Report | 生成周报 |
