# Weekly Report - 众安车险周报生成器

## 概述

根据用户提供的周报数据，自动生成符合众安车险品牌风格的 HTML 周报页面。

## 公开接口

| 接口 | 类型 | 说明 |
|------|------|------|
| `/weekly-report` | 命令 | 触发周报生成流程 |

## 依赖关系

### 上游依赖
无

### 下游消费
无

## 关键文件

| 文件 | 角色 |
|------|------|
| `SKILL.md` | 技能定义和工作流程 |
| `templates/weekly-report-template.html` | HTML 模板 |

## 设计决策

- 基于 Tailwind CSS + 内联样式
- 样式映射：highlight=#3b82f6, accent=#10b981, warn=#f97316
- 动态构建 HTML 结构，非简单字符串替换
- 输出到 `output/weekly-report-{YYYY-MM-DD}.html`
