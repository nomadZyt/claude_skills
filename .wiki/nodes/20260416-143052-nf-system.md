# NF System - New Feature 开发系统

## 概述

用 Markdown 规范驱动开发的 NF 系统，支持并行运行 4-8 个 Coding Agent，适合中大型项目开发。

## 公开接口

| 接口 | 类型 | 说明 |
|------|------|------|
| `/nf-new` | 命令 | 创建新 NF |
| `/nf-status` | 命令 | 查看所有 NF 状态 |
| `/nf-explore` | 命令 | 加载项目上下文 |
| `/nf-verify` | 命令 | 验证代码 |
| `/nf-close` | 命令 | 关闭并归档 NF |
| `/nf-deep` | 命令 | 并行深度分析 |

## 依赖关系

| 文件 | 角色 |
|------|------|
| `SKILL.md` | 技能定义和使用说明 |
| `templates/NF-TEMPLATE.md` | NF 文档模板 |
| `templates/FEATURE_INDEX.md` | NF 索引模板 |

## 设计决策

- NF 粒度：Small 5-10 分钟，Medium 15-20 分钟，Large 30+ 分钟
- 并行上限：4-6 个 Agent（最多 8 个）
- Commit 格式：`NF-XXX: [动词] [描述]`
