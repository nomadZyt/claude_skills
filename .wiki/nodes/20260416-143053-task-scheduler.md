# Task Scheduler - 多任务并发调度器

## 概述

基于 Claude Code 原生 Team 机制的多任务并发调度器，支持最多 4 个 Agent 并行执行，自动管理任务依赖关系。

## 公开接口

| 接口 | 类型 | 说明 |
|------|------|------|
| `/task-scheduler start` | 命令 | 启动调度器 |
| `/task-scheduler status` | 命令 | 查看进度 |
| `/task-scheduler stop` | 命令 | 停止调度器 |
| `/task-scheduler check` | 命令 | 检查状态并补救调度 |
| `/task-scheduler report` | 命令 | 生成执行报告 |

## 依赖关系

## 设计决策

- 使用 Team 机制（TeamCreate + TaskCreate + SendMessage）替代 Cron 轮询
- Agent 完成后主动通知调度器，无需轮询
- 最大并发数：4 个 Agent
- 支持任务依赖关系（`[依赖:X,Y]` 语法）
- 优先级队列调度：High(3) > Medium(2) > Low(1)
