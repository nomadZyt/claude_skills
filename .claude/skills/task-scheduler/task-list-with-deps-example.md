## 依赖关系图

```
任务 1: 设计数据库 Schema（无依赖，立即启动）
  ├── 任务 2: 实现用户认证 API [依赖:1]

  ├── 任务 3: 实现商品管理 API [依赖:1]
  │     └── 任务 5: 开发前端商品列表页 [依赖:3]
  └── 任务 6: 编写集成测试 [依赖:2,3]
        └── 任务 7: 部署到测试环境 [依赖:4,5,6]
```

## 调度顺序说明

1. **第一轮**：任务 1 无依赖，立即启动
2. **第二轮**：任务 1 完成后，任务 2、3 解锁，同时启动（并发）
3. **第三轮**：任务 2 完成后启动任务 4；任务 3 完成后启动任务 5；任务 2+3 都完成后启动任务 6
4. **第四轮**：任务 4、5、6 全部完成后，启动任务 7

最大并发数为 4，调度器会自动控制同时运行的 Agent 数量。
