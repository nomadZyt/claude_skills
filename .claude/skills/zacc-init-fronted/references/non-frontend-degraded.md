# 非前端项目：门禁与降级初始化

> 供 `zacc-init-fronted` 在「步骤 0」判定非前端后，经用户确认继续时使用。本技能仍以 **CLAUDE.md + .claude/AI_RULES.md** 为产出，但分析维度从「六维前端」收缩为「可落地的通用工程上下文」。

## 何为「前端项目」（本技能口径）

在 **步骤 0** 中，若满足以下任一条件，则视为 **前端项目**，走标准流程（步骤 1～7 原文）：

- `package.json` 的 `dependencies` / `devDependencies` 中可识别常见 **Web UI 栈**（完整框架清单见 `tech-stack-detection.md` 的「框架」识别表，包括 React / Vue / Angular / Svelte / Solid / Next / Nuxt / Remix / Umi 等）。
- 虽依赖表不典型，但存在明确前端工程信号：例如根目录存在 `vite.config.*` + 明显浏览器端入口，且以组件/页面组织代码（需 Read 少量文件佐证）。

> **信源说明**：前端框架的判定关键词统一以 `tech-stack-detection.md` 为唯一信源。本文件不再重复列举具体框架名称，避免两处列表不同步。

以下情况通常判为 **非前端项目**（须走步骤 0 门禁）：

- 无 `package.json`，或仓库主要为 **Go / Java / Python / Rust** 等非浏览器 UI 技术栈。
- 仅有 `package.json`，但依赖显示为 **CLI、纯 Node 库、BFF、服务端**，无上述 UI 框架/元框架。
- **Monorepo**：根目录无法确定前端子包；若用户选择继续，应 **AskUserQuestion** 让用户指定要初始化的子目录（或默认仅描述仓库整体，并在 CLAUDE.md 中注明「未绑定具体前端包」）。

> 边界模糊时（例如全栈仓库）：先按非前端告知用户，由用户选择是否仍要「降级初始化」整个仓库或指定子路径。

## 步骤 0：告知并询问（必须先做）

1. **明确告知**（示例语气，可改写）：  
   「当前仓库在本技能口径下判定为 **非前端项目**（或未识别到典型 Web 前端栈）。`zacc-init-fronted` 默认面向前端六维分析。」
2. **询问是否继续**：使用 **AskUserQuestion**（或等价交互），选项建议：  
   - **继续**：使用下方降级策略生成/更新 `CLAUDE.md` 与 `.claude/AI_RULES.md`。  
   - **取消**：结束流程，**不生成或修改**上述文件（除非用户明确要求仅保留说明性输出）。
3. 若用户选择 **取消**：礼貌结束，可提示若实际需要前端子目录或 Wiki，可改用 **`zacc-wiki-fronted`** 或指定路径后重试。

## 降级策略（用户选择「继续」后）

| 标准步骤 | 降级做法 |
|---------|----------|
| **1 项目信息** | 无 `package.json` 时：按仓库实际读取 `go.mod`、`pom.xml`、`pyproject.toml`、`Cargo.toml` 等 + `README.md`；有 `package.json` 但非前端时：如实记录依赖与脚本，**不要虚构**前端框架。 |
| **2 结构分析** | 不强行假设 `src/`：用 Glob/LS 在常见源码根下扫描（示例：Go → `cmd/`、`internal/`；Java → `src/main/java`；Python → `src/` 或与包名同名目录；Rust → `src/`；Node 非前端 → `lib/`、`src/`）。归纳模块/分层，**不使用**「pages/router 专属前端」话术硬套。 |
| **3 规范提取** | 优先该语言/生态的配置（如 `.golangci.yml`、`checkstyle`、Python `ruff`/`black`）；无则记录「未检测到」而非臆造。 |
| **4 数据流 + 页面流** | **跳过**「路由 → 视图」前端链路；改为 **简要**描述：请求/入口 → 服务层 → 存储/外部依赖（或该仓库实际分层），仅作步骤 5～6 的输入。 |
| **5 红线** | 四类红线改为 **非 UI 语境**：技术栈/构建/包管理不变；目录与分层约定；命名与风格；**不**写「组件 props / 前端路由」类规则，改为接口契约、公共 API、数据层约束等 **与仓库类型相符** 的条目。 |
| **6 生成文件** | 使用模板时在「项目概述 / 技术栈」中 **显式标注**：`初始化模式：非前端降级（zacc-init-fronted）`，避免后续 AI 误当前端 SPA。模板缺省时允许 **适度自由填充**，但须与仓库证据一致。 |

## 步骤 7 摘要补充

降级完成时，在输出中增加一行，例如：

- `初始化模式：非前端降级（已征得用户同意继续）`
