# 更新日志

## 更新日志

### v2.0.0（2026‑04‑16）

- **技能重命名与重构**
  - 技能重命名为 `zacc-prd-by-html`（原 `prd-reverse-engineer`），统一命名规范。
  - 新增 Plan Mode 执行策略：PRD 生成前必须经用户审批，审批通过后才落盘。
  - 新增输入类型门禁（步骤 0）：自动判定 HTML 文件/目录/ZIP/远程 URL，非 HTML 输入（PDF/图片/Figma）给出引导提示。
  - 新增页面关系建模（步骤 2）：多文件原型自动构建导航图谱，识别入口页面和页面层级。
  - 六维度信息提取（步骤 3）：产品概述、用户流程、信息架构、功能需求、交互设计规范、数据需求，每个维度标注置信度。
  - PRD 按模板组装（步骤 4）：只生成有对应提取结果的章节，不臆测原型中不存在的内容。
  - 文件已存在时三选一：覆盖（自动备份）/ 追加日期后缀 / 取消。
  - 多页面并行分析：>5 页面时按页面分配 Agent（最多 4 个）。
  - 包含 7 份参考文档。

### v2.0.1（2026‑04‑29）

- **输出目录调整**

  - 涉及文件：`SKILL.md`、`USAGE.md`。
