# 输入类型检测与处理

> 供 zacc-prd-by-html 步骤 1 使用，判断输入类型并选择对应处理策略。

## 输入类型判定

| 输入形态 | 判定条件 | 示例 |
|----------|----------|------|
| **单文件 HTML** | 路径指向一个 `.html` 文件 | `docs/prototype.html` |
| **HTML 目录** | 路径指向目录，内含多个 `.html` 文件 | `docs/prototype/` |
| **ZIP 压缩包** | 路径指向 `.zip` 文件，需先解压 | `docs/prototype.zip` |
| **远程 URL** | 以 `http://` 或 `https://` 开头 | `https://example.com/prototype` |

**判定流程**：

1. 检查 `$ARGUMENTS` 是否以 `http` 开头 → 远程 URL
2. 检查路径是否指向 `.zip` 文件 → ZIP 压缩包
3. 检查路径是否指向 `.html` 文件 → 单文件 HTML
4. 检查路径是否为目录且包含 `.html` 文件 → HTML 目录
5. 以上均不满足 → 提示用户重新指定输入

## 各类型处理策略

### 单文件 HTML

- 用 Read 读取完整内容
- 提取内联 CSS（`<style>` 标签）和 JS（`<script>` 标签）
- 提取外链资源路径（CSS/JS 文件），逐个读取
- 作为单一页面分析

### HTML 目录

- 用 Glob 扫描目录下所有 `.html` 文件
- 识别入口文件（`index.html`、文件名含 `home`/`main`/`landing` 的文件）
- 分析页面间导航关系（`<a href>` 链接）
- 多页面之间建立关联图谱
- **文件数量阈值**：≤5 个文件全量分析；6-15 个文件全量扫描但重点分析入口和关键页面；>15 个文件仅分析入口+用户指定的页面，其余列表记录

### ZIP 压缩包

- 用 `unzip -l` 列出文件清单
- 用 `unzip -d /tmp/html-to-prd-extract` 解压到临时目录
- 按单文件或目录策略处理解压后的内容
- 分析完成后删除临时目录

### 远程 URL

- 用 WebFetch 抓取页面内容
- 单页面直接分析
- 如需分析关联页面，提示用户下载后以目录方式输入
- 抓取失败时提示用户手动下载后重新执行

## 输入预处理

对所有类型执行：

1. **编码检测**：非 UTF-8 文件尝试转码，失败则提示
2. **资源完整性**：检查外链 CSS/JS 是否可访问，不可访问的标注"资源缺失"
3. **页面可解析性**：HTML 结构是否完整（有 `<html>`/`<body>` 标签），片段式 HTML 标注"非完整页面"
