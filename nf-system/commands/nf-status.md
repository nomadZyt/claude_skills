# /nf-status - 显示 NF 状态

## 目的
显示所有 New Feature 的当前状态。

## 步骤

1. **读取索引**
   - 加载 `docs/features/FEATURE_INDEX.md`

2. **解析并显示**
   按以下顺序显示：

   ### 进行中的功能
   | NF | 标题 | 状态 | 工作量 | 优先级 |
   |----|------|------|--------|--------|
   | ... | ... | ... | ... | ... |

   ### 待验证
   | NF | 标题 | 完成日期 |
   |----|-------|----------|
   | ... | ... | ... |

   ### 最近完成（最后 5 个）
   | NF | 标题 | 完成日期 | 备注 |
   |----|------|----------|------|
   | ... | ... | ... | ... |

3. **提示下一步操作**
   ```
   你想做什么？
   - "处理 NF-XXX" → 开始实现
   - "创建新 NF" → 运行 /nf-new
   - "关闭 NF-XXX" → 运行 /nf-close
   ```

## 输出格式

使用 Markdown 表格。保持清晰易读。

## 边界情况

- 没有进行中的 NF → 显示"没有进行中的功能，用 /nf-new 创建一个"
- 索引文件缺失 → 建议运行 nf-init
