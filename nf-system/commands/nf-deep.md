# /nf-deep - 深度并行分析

## 目的
对于复杂问题，从多个角度并行分析。

## 何时使用
- 复杂的架构决策
- 没有明显解决方案的问题
- 不熟悉的技术/领域
- 需要彻底探索的高影响决策

## 分析角度

对每个适用的角度运行探索：

### 1. 算法角度
- 性能影响
- 时间/空间复杂度
- 可扩展性问题

### 2. 结构角度
- 架构模式
- 代码组织
- 关注点分离

### 3. 渐进角度
- 迁移路径
- 向后兼容性
- 发布策略

### 4. 环境角度
- 依赖项（新库、服务）
- 部署要求
- 基础设施变更

### 5. 安全（如适用）
- 攻击面
- 数据保护
- 认证/授权

## 流程

1. **清晰定义问题**
   ```
   问题：[我们试图回答什么？]
   上下文：[相关 NF 或情况]
   ```

2. **运行并行分析**
   对每个角度探索：
   - 关键考虑因素
   - 潜在解决方案
   - 权衡

3. **综合发现**
   创建汇总表：
   | 角度 | 关键洞察 | 建议 |
   |------|----------|------|
   | 算法 | ... | ... |
   | 结构 | ... | ... |

4. **给出建议**
   ```
   ## 推荐方案

   [清晰的建议及理由]

   ## 下一步

   1. [行动 1]
   2. [行动 2]
   ```

## 输出格式

```markdown
# 深度分析：[问题]

## 摘要
[2-3 句话概述]

## 按角度分析

### 算法角度
[发现]

### 结构角度
[发现]

...

## 建议
[清晰建议]

## 置信度
[高/中/低] + 理由
```

## 提示

- 如果不相关，不要强制使用所有 5 个角度
- 目标是可操作的洞察，不只是分析
- 时间限制：每个角度最多 10-15 分钟
